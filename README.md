**Simple FPS Prototype**

A lightweight First-Person Shooter (FPS) prototype built in Unreal Engine, focusing on core movement mechanics and weapon handling. This project serves as a demonstration of basic gameplay loops and custom asset integration.

🎮 Features

Combat Mechanics

- Shooting System: Hitscan/projectile logic.
- Reload Mechanism: Functional ammo counting and reload logic.
- Weapon Sway: Procedural mouse sway animation to add weight and realism to the weapon movement while looking around.
- Simple Graphics Setting UI - Written in c++.

Animation & Assets

- Custom Weaponry: The gun model was rigged from scratch in Blender before being imported into Unreal Engine.
- Custom Animations: Includes bespoke animations for firing, reloading, and idle states.
